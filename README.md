Write a complete story in exactly six words, on anything. A judge model compares entries two at a time against the published brief, and the top three take the $5 pool.

The story: "Medal arrived; the soldier never did." — a medal ceremony after a loss, told in six words: the arrival against the absence, and everything unsaid about who receives it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
